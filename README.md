# Ejercicios-en-Aplicaci-n-Web
Combinar los tres ejercicios básicos en una sola aplicación web, que tenga una página principal con un menú y se pueda navegar a cada uno de los ejercicios, y se pueda navegar de cada ejercicio a la principal y al resto de ejercicios.  Utilizar la funcionalidad require para no escribir el menú de navegación muchas veces.
